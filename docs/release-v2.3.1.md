# 光屿 AI v2.3.1

生成的作品现在会自动保存到本机，并在网页“作品库”集中查看、播放与下载。修复部分平台仅保留临时 URL、链接过期后无法查看作品的问题。

- 生成完成后先持久化结果，再下载原文件；文件保存失败不会丢弃生成结果或重复提交付费请求。
- 作品库展示保存数量与状态，可筛选已保存、待保存、图像、视频、音频和文本记录。
- “重试保存”只下载缺失文件。升级首次启动尝试补存旧链接；原链接已失效且无本机副本的旧作品无法恢复。
- 支持常见图像、视频和音频格式；单文件最大 512 MiB，原子落盘。下载不携带模型 API 密钥或 Cookie，逐跳检查地址并固定已验证的 DNS 地址。
- 数据仍保存在程序旁的 data 文件夹；升级前请保留完整 data，网页不是云端存储。

验证使用隔离本机模拟接口，不调用真实付费模型。源码共 108 项检查（70 单元、18 HTTP、20 回归）；Windows 便携包另有 25 项运行检查，包含远程作品保存和重启保留。

下载完整 Windows ZIP 并解压后运行 GuangyuAI.exe，无需安装 Python。SHA256SUMS.txt 用于校验安装包。详见仓库数据与升级文档。
