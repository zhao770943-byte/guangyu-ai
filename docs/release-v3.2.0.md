# 光屿 AI 3.2.0

本次源码同步整合 2.3.2 之后的工作台升级，包括小说制片、六 AI 协作、定稿与分镜画布、项目管理、声音工作流和统一界面。

## 主要变化

- 以项目组织原文、剧本、人物／场景／道具资产、分镜、声音、任务与成片。
- 六个 AI 分角色配置；自动模式执行润色、独立审稿、实际图片检查、有限修复与并行生成。
- 当前版本的分镜审核与视频提交关联；保留逐镜五项实际视听验收，最终接受与发布仍由用户决定。
- 对白账本保留原文引语、问答顺序、删改说明；新项目默认约 30 镜，可进一步细分至 36／40 镜等计划。
- 前作锁定资产可复用；原图像素、来源版本和引用镜头可见，修改设定后需要重新检查。
- 3.2 项目总览显示真实阶段、待办与任务；分镜新增节奏／对白筛选；声音按角色编辑、试听与导出台本。
- 模型接入先读取厂商目录，再下拉选择类型与型号，已有来源复用后端保存的凭据。
- 开源漫剧制作与工作台开发 Skill，以及只读项目审计工具。

## 数据与升级

停止服务并备份整个 `data/` 后再升级。仓库不附带个人作品、小说全文、模型密钥、本机制作日志或私人数据库。新增数据结构保留已有项目；旧项目不会自动开始生成，也不会被自动标记为验收完成。

自动模式和多镜头会增加模型调用，须配置实际可用的模型与请求上限。模型权限、付费结果、图片质量和音视频质量取决于真实平台，离线测试不替代这些验收。

## 构建与验证

仓库包含后端单元测试、前端状态与 DOM 契约检查、隔离 HTTP 回归和 Windows 便携运行检查。GitHub Actions 在主分支推送后执行；具体通过状态以对应提交的 Actions 记录为准。

主分支同步本身不会替换既有 Release 安装包；应用版本以源码 `VERSION` 或安装包 `build-info.json` 为准。
