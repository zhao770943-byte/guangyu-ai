# 光屿 AI v2.2.0

本次更新重做创作工作台和模型接入流程，让参数设置、作品预览与主要操作有更明确的位置。

## 界面与工作流

- **导航与信息密度**：调整导航、标题、文字层级和控件间距，将更多空间留给创作内容。
- **工作台独立滚动**：桌面图像／视频页面的参数区与预览区分别滚动，生成按钮保留在参数区底部；窄屏采用顺序布局。
- **模型管理表格**：按行查看模型名称、ID、地址、用途与协议；支持用途筛选、搜索、编辑和移除。
- **实际两步接入**：第一步只处理平台、API Key 和基础地址，由用户明确点击“读取模型”；第二步搜索并选择模型，核对连接预览后接入。
- **可确认的自动匹配**：选择模型后填入默认名称、匹配已识别的用途与协议。未知模型需要主动选择用途才能保存；高级协议和请求地址可展开核对。
- **手动与高级入口**：没有模型列表时可手填模型 ID／接入点；自定义认证、列表路径、请求模板和响应映射按需打开，不占据基础接入流程。
- **独立目录协议**：模型列表可以使用与生成不同的协议并随连接保存；重新编辑、读取目录或刷新时保留配置，手动模型与自定义名称也可继续使用。

Key 输入框失去焦点不会触发读取。读取目录和保存连接均不会发起生成，实际创作仍由工作台中的生成按钮提交。

## 使用与升级

下载本 Release 的 `GuangyuAI-v2.2.0-windows-x64.zip`，完整解压后运行 `GuangyuAI.exe`，保留配套 `_internal/`。Windows x64 便携版无需预装 Python，模型 API 地址、密钥与费用仍由各自平台提供。

从旧版本升级前，等待任务结束，使用旧目录中的停止脚本关闭服务并备份完整 `data/`。将新版解压到新目录，复制自己的 `data/` 到新 EXE 旁再启动。不要混搭新旧依赖目录或同时让两个实例读写同一份数据。

## 验证状态

本轮已在真实浏览器的 **1280×720 桌面尺寸和 390×844 窄屏尺寸**检查界面与交互：两步读取、搜索选择、未知用途强制确认、保存重开保留自定义名称、手填模型刷新保留，以及失败提示和手动后备入口。本机模拟助手返回输入 24、输出 76、合计 100 Token，已在用量页核对显示。

本轮自动化检查 **102 项全部通过，0 失败**：源码回归 81 项（43 项单元／目录检查、18 项 v2 集成、20 项基础回归），本版本 EXE 便携运行检查 21 项。便携检查实际验证了中文目录、无 Python 的 PATH、不同当前目录、独立向导 JS/CSS 资源加载、图片组件、DPAPI、重启保留、端口冲突以及活动任务期间拒绝停止。

最终 ZIP 使用同一版本代码，同步最终文档后重新压缩并复核，附对应 `SHA256SUMS.txt`。通过结果适用于本次验证的构建和机器，不代表所有 Windows 环境均已验收。

`docs/images/` 已更新为本轮浏览器截图。模型目录、助手回答与用量示例使用隔离本机模拟接口，没有外部付费模型调用，不代表真实供应商的权限、额度或输出质量。

模型目录能读取不代表账号拥有生成权限或额度；未知 Token 保持未知，应用用量不是平台完整账单。首尾帧、高级参数和可用协议仍按连接实际能力启用。真实供应商的权限、计费与生成质量需使用自己的配置验证。
