# 定稿与分镜画布（2.5）

左侧导航打开“定稿与分镜”。它独立于视频生成，管理多个定稿、各自版本和每个分镜的实际参考输入。

画布占满工作区，不再保留左侧编辑栏或右侧节点属性栏。项目名称只在顶部显示并直接编辑；切换、新建和导入导出在“项目”菜单中，默认模型、画幅和故事背景在“项目设置”中。添加角色、场景、道具、风格、分镜与导入图片位于画布顶部。

每个节点的图片下方就是提示词输入框；分镜节点可在“画面提示词”和“视频提示词”之间切换，分别保留内容。节点底部提供生成和候选采用，模型、参考、历史版本和导入操作从该节点的“设置 / 版本”打开，用完关闭，不占画布宽度。

## 先定稿，再编排镜头

1. 新建项目，选择默认图像模型；添加角色、场景、道具或风格定稿节点。
2. 角色节点默认使用16:9的“面部＋正侧背”设定板模板。填写人物面貌、发型、服装、鞋、配饰和风格；生成描述会要求四个视图保持同一角色。也可以上传已有设定板，或在画布粘贴截图。
3. 节点底部的“生成”只提交该节点；批量生成从画布“操作 → 生成所选节点”进入，每节点一条图像任务。生成后先检查候选，再点击“采用候选”或版本窗口中的“采用这张图片”。生成成功本身不等于视觉验收。
4. 添加分镜节点。拖动定稿右侧输出圆点到分镜左侧输入圆点，或在该节点“设置 / 版本”的“实际参考输入”中勾选节点。每个镜头可以使用不同的角色、场景、道具组合，也可以引用另一张已采用的分镜。
5. 描述这个镜头的单一静态画面，再生成、检查并采用。系统会按连线顺序传入参考图，不把所有项目定稿一概传给每个镜头。

一个项目最多64个节点，每节点最多8个参考。实际模型可能有更小上限，以接口校验为准。不允许循环引用；上游还没有采用图片或需要复核时，下游不会静默降级为文生图。一次最多提交12个节点，仍受工作台已有队列上限约束。批量操作不会自动生成并采用上游图片，应先完成上游定稿，再生成下游。

## 画布与剪贴板

- 拖动节点标题移动；空白处拖动框选；Shift/Ctrl点击多选。
- 滚轮缩放，按住空格拖动或用鼠标中键平移；“适配画布”显示全部节点。
- “整理”按当前画布比例安排节点并适配显示，可撤销；旧项目不会自动改写节点位置。“全屏”进一步扩大画布，在全屏内仍可添加、编辑和保存。
- Ctrl+C/V复制粘贴选中节点。选中集合内的连线随节点复制并重映射；同一项目可保留到已有外部节点的引用，跨项目不存在的外部引用不带入。复制的是当前采用图片与编辑配置，不会重发历史生成任务。
- 在文字框内，Ctrl+C/V/Z仍是正常文本操作。Ctrl+S保存项目。
- Ctrl+V粘贴剪贴板图片，或拖入PNG/JPEG/WebP文件，创建新定稿节点。单张最大10MiB。
- 节点“已采用图片”下可复制图片到系统剪贴板、下载原图；需要浏览器允许剪贴板写入。照片复制时会转为剪贴板支持的PNG，不覆盖原文件。
- “上传 / 粘贴图片”和“从作品库选择”给当前节点添加版本；往画布直接粘贴图片则新建节点。
- Ctrl+Z/Y撤销重做未保存的本地编辑；保存后清空编辑撤销栈。已采用图片使用历史版本下拉框切换。

## 版本与复核

每次生成记录引用节点、采用版本及图片ID。重新生成先产生候选，不覆盖当前采用版本。更换上游定稿或修改描述后，下游旧图片和任务仍保留，并标记“需要复核”。

可以重新生成后采用，或检查现有图片后点击“已复核，保留此图”。复核记录会生成新的采用版本，保留此前记录。尚未复核的旧图不能被直接送往视频，以免再次混用旧素材。

## 送往视频

### 多张分镜生成一条整片视频

画布顶部点击“生成整片视频”，或在视频工作台点击“从分镜生成整片”选择已保存项目。勾选 2–9 个已采用图片的分镜，用上下箭头调整顺序，填写逐镜动作、运镜或对白。图片需复核、画幅需一致。

整片时长可填写 1–600 秒。填写总时长会均分给所选镜头；单独调整某一镜头时长时，总时长随合计更新。换模型会保留总时长，重新计算拆段计划。保存配置会保存顺序、时长、提示词、模型和提交方式。

提交前会显示任务数、请求秒数和最终使用秒数。例如模型固定每次 15 秒，35 秒整片会请求 15+15+15 秒，最终使用 15+15+5 秒。平台可能按完整 45 秒请求计费。模型支持多个时长档位时，尾段使用能够容纳剩余内容的最小档位；每段参考图数量也遵守模型上限。

- 串行：上一段生成并保存到本机后，提交下一段。
- 并行：单个整片最多同时处理 3 段，同时遵守工作台全局队列容量。
- 不需要拆段或裁切时，仍只创建一次模型任务。

拆出的片段按原分镜顺序生成，各段包含对应参考图和局部时间轴。全部片段保存后，本机自动合成一条 MP4，保留音轨；无声片段补静音。输出统一为 30 FPS、最高 1080p，超出预期尾长的部分裁去。结果和原片段一起进入项目作品合集。段间采用顺序拼接，模型的角色一致性、动作衔接与每镜精确时长仍需检查。仅首尾帧的 H3 不在此多图流程的模型列表中。

整片进度可查看各段。失败时保留成功片段，暂停未提交片段；“仅重试此段”会创建一次新的模型请求，保留原失败记录。结果未确认且有平台 ID 时使用“查询原任务”，保存失败使用“重试保存”，本机合成失败使用“重试本机合成”。这些查询、保存和合成都不会重复调用模型生成。

重复确认同一提交不会产生第二套任务。重启可恢复尚未提交的排队片段及已有平台 ID 的查询；已交接提交但状态不明的片段不自动重发，避免重复计费。用于未完成整片的原片段暂不能删除。整片本机合成记录不计为额外模型请求。

### 单镜头打开视频草稿

在分镜节点图片下方切换到“视频提示词”，填写后点击“视频草稿 →”，使用当前视频模型；也可在该节点“设置 / 版本”的“送往视频”中更换模型后打开草稿。系统使用当前采用图片，替换视频草稿的参考图和提示词，并同步该镜头画幅；不会创建视频任务。目标模型不支持参考图或画幅时会提示更换，不能静默切到横屏。视频时长仍按实际模型支持值设置。

## 保存、迁移和边界

项目保存到本机SQLite的visual_projects表。旧storyboards表保留，使用“导入旧分镜”可复制为新画布；同一旧项目重复导入会打开同一个导入项目，不覆盖原项目。旧项目包含旧图片时，需在新画布用作品库或上传替换为正确版本。

导出JSON包含节点、连线、描述和本机素材ID，不含密钥或请求鉴权。导入会添加到当前画布，适合同一本机工作区内复用；跨电脑迁移请保留完整data目录，单独JSON不包含图片。保存是显式操作，未保存离开或关闭时应先保存。

此工作台借鉴ComfyUI节点画布与快捷键交互，不执行ComfyUI模型加载器、采样器或任意自定义节点。多视图是生成模板，实际一致性取决于模型结果，需要逐图确认。
