# 数据、备份与升级

## 数据存在哪里

便携版默认在 `GuangyuAI.exe` 所在文件夹创建 `data/`。源码版默认使用源码目录下的 `data/`。`_internal/` 是便携版运行依赖，不是个人数据目录。

| 位置 | 内容 |
| --- | --- |
| `data/workspace.sqlite3` | 模型连接、加密密钥、任务、用量与会话 |
| `data/uploads/` | 上传的参考图、首帧与尾帧 |
| `data/media/` | 保存到本机的 Base64 图像和 OpenAI 视频 |
| `data/service.log` | 本机服务启动与异常信息 |

普通远程媒体结果可能只保存 URL，链接可能过期；需要长期保留的作品请及时另存。移除草稿中的图片不会自动删除本机素材。

API Key 使用当前 Windows 用户的 DPAPI 加密；跨电脑或跨 Windows 用户复制数据后，通常需要重新填写密钥。其他创作记录、提示词、素材和媒体链接也可能包含私人信息，请勿直接分享整个数据文件夹。

## 备份

1. 等待当前任务结束。
2. 使用 `停止光屿AI.cmd` 或 `GuangyuAI.exe --stop` 停止服务；源码版使用 `python launcher.py --stop`。
3. 复制完整 `data/` 到自己的备份位置。

关闭浏览器不会停止后台服务。有任务运行时，正常停止操作会拒绝关闭；不要为了备份强行终止正在提交的生成请求。

## 升级便携版

1. 使用旧版本目录中的停止脚本停止旧服务，再备份数据。
2. 将新版 ZIP 完整解压到新文件夹，保留配套的 `_internal/`。
3. 将备份的 `data/` 复制到新 `GuangyuAI.exe` 旁，再启动新版。
4. 确认连接与记录可用后再决定如何保留旧版本。不要同时启动两个版本读写同一份数据。

不要将新版 `_internal/` 与旧版文件混搭，也不要只复制单个 EXE。没有自动下载或自动升级流程。

## 改端口或数据目录

默认地址是 `http://127.0.0.1:8786/`。如果端口被其他程序、旧版本或使用不同数据目录的实例占用，应用会拒绝接管，不会终止那个程序。升级时请先用旧版本自己的停止脚本关闭旧服务；需要并行使用独立实例时，可在 PowerShell 中设置自己的端口后启动：

```powershell
$env:GUANGYU_PORT = '8787'
.\GuangyuAI.exe
```

也可以在启动前设置 `GUANGYU_DATA` 指向专用数据目录。停止命令应使用与启动时相同的端口和数据环境。自定义数据目录不要与公开源码仓库、网盘共享目录或其他实例混用。

## 运行边界

服务仅监听本机回环地址，没有登录和多用户权限体系。不要把端口直接开放到公网。应用不会随 Windows 自动启动；关机、休眠、联网状态与平台可用性会影响生成。

生成 POST 不自动重试。重启后，已有平台任务 ID 的查询可继续；提交结果不确定时会标为中断。重新生成前请先核对平台是否已受理，以免重复计费。
