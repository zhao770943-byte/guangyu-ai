# 光屿 AI v2.3.0

模型接入改为“文本 / 音频 / 图像 / 视频 → 厂商 → 对应型号”三步流程。选择型号不会改变用户先选的类型，M 系列文本模型不再混入图像目录。

- 按类型筛选厂商与模型，保留一键获取、目录搜索和官方 API Key 直达链接。未知类型默认隐藏并要求确认。
- 新增音频工作台，支持 OpenAI Speech 和 MiniMax 同步语音合成、音色、语速、播放与下载。语音识别和实时语音在目录中标记待适配，不能误用合成接口。
- 新增 MiniMax 原生图像协议，自动填写 `/image_generation`；语音使用 `/t2a_v2`，并检查业务错误状态。
- MiniMax 图像、语音提供单独标注的官方公开型号清单，用于账户目录未返回这些条目的情况；不冒充密钥授权结果。
- 用量与历史加入音频类型和生成数量；未返回 Token 时保留未知，不记为零。

升级保留原有 `data` 目录。已有密钥、模型名称、历史记录不自动修改，也不自动重提失败任务。语音和图像的原生接口按官方文档及隔离模拟接口验证；真实账户额度、权限、网络和生成质量需实际调用验证。视频专有协议、语音转写和实时通话仍需要额外适配。

验证：61 项单元检查、18 项 HTTP 集成、20 项核心回归，以及 23 项 Windows EXE 便携运行检查，共 122 项通过。浏览器完成四类选择、目录筛选、协议预览、模拟语音播放与音频用量验收。
