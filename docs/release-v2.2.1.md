# 光屿 AI v2.2.1

本次更新将模型接入统一为“一键获取模型 → 从列表选择”，无需手动输入模型 ID。

## 接入流程

- 第一步选择平台、填写自己的 API Key 并核对基础地址，固定点击“一键获取模型”。第二步搜索和选择返回的模型，也可再次点击同名按钮重新获取。
- 所有平台预设均按当前地址尝试请求模型目录，OpenAI 兼容与自定义 JSON 默认尝试 `/models`，也可配置其他目录相对路径。获取失败或返回空列表时显示实际提示，检查连接设置后可重试。
- 新增连接不再提供模型 ID 手填入口。编辑已保存连接时保留原模型和自定义名称；选择未知模型后仍需主动确认用途。
- 选择平台后可在新标签页打开官方 API Key 页面，Ollama 与 LM Studio 则提供本机服务下载入口。应用提供入口，不代为注册、申请或购买额度。

读取目录不会生成内容，也不会在保存连接前持久化新输入密钥。平台预设允许发起获取，不代表每个官方入口都提供模型列表；模型出现在目录中也不保证生成权限、额度或协议兼容。

## 使用与升级

下载本 Release 的 `GuangyuAI-v2.2.1-windows-x64.zip`，完整解压后运行 `GuangyuAI.exe`，保留配套 `_internal/`。Windows x64 便携版无需预装 Python。

升级前等待任务结束，使用旧目录中的停止脚本关闭服务并备份完整 `data/`。将新版解压到新目录，复制自己的 `data/` 到新 EXE 旁再启动；不要混搭新旧依赖目录或同时让两个实例读写同一份数据。详情见 [数据与维护](https://github.com/zhao770943-byte/guangyu-ai/blob/v2.2.1/docs/data-and-upgrades.md)。
