# 光屿 AI v2.1.0

光屿 AI 的首个公开发行版本：在自己电脑上连接图像、视频与语言模型 API，使用中文创作工作台、网页 AI 助手和模型用量页。

## 下载与使用

下载 `GuangyuAI-v2.1.0-windows-x64.zip`，完整解压后双击 `GuangyuAI.exe`。无需预装 Python；请保留旁边的 `_internal/`。首次启动后在“接口设置”选择平台，填写自己的 API Key，读取并选择模型；没有列表接口时可手填模型 ID。

支持 Windows x64。模型费用由所选平台收取，安装包不提供共享密钥或额度。个人数据默认保存在程序旁的 `data/`；停止后备份该文件夹再升级。

## 包含功能

- 图像参考输入、视频首帧／首尾帧工作台及按模型能力启用的高级参数。
- 可附带当前草稿的网页 AI 助手，以及主动采纳到创作草稿。
- 已接入与历史模型列表、本应用 Token 记录、趋势、请求明细和 CSV。
- 多平台原生适配及自定义 JSON 请求、查询与用量字段映射。
- 14 个平台地址预设、模型列表自动读取与搜索、已识别用途／协议匹配，以及专有接入点手填。列表读取不生成内容，保存前不持久化新输入密钥。

OpenAI Videos 当前适配首帧；尾帧需接入支持该能力的自定义接口。Token 统计来自本应用保存的响应，不是账户账单；未返回值显示未知。

## 发布验证

源码回归已通过 **77 项检查，0 失败**：39 项单元／发现检查、18 项 v2 集成检查、20 项基础回归。浏览器已验证平台地址填入、输入 Key 后自动读取模拟模型、搜索选择、用途／协议匹配、保存与编辑，以及基础地址变化时的密钥保护。

`docs/images/model-discovery-fixture.jpg` 展示的是本机模拟目录；列表数据不代表真实供应商账号已获授权。

Windows x64 便携包另通过 **20 项隔离运行检查，0 失败**，合计 **97 项通过**（77 项源码 + 20 项便携包）。实际使用中文目录、无 Python 的 PATH 和不同当前目录启动 EXE，验证了图片组件、只读模型发现且不自动保存、DPAPI 密钥保护、重启保留、端口冲突处理，以及活动任务期间拒绝停止。

发布 ZIP 附 `SHA256SUMS.txt`。上述测试证明本次构建在测试机器上通过，不代表所有 Windows 策略、硬件与安全软件环境都经过验证。

测试使用隔离模拟接口，没有验证付费供应商的权限、额度或生成质量。更多操作与边界见 README、使用说明和验收记录。
