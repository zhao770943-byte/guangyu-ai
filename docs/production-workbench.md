# 3.2 项目制作工作台

制作顺序是：原文与参考 → 剧本与对白 → 定稿资产 → 分镜与拍摄单 → 视频与声音 → 验收与交付。

## 项目总览

总览从当前项目状态计算六阶段成果和待办，显示模型请求额度、进行中任务、失败原因和下一步。剧本计划时长与主选成片实际时长分别展示；历史成片不会被新规则自动改成已审核。

## 六 AI 分工

| 角色 | 负责内容 |
| --- | --- |
| 导演 | 原文结构、人物和场景资产、分集方向 |
| 编剧 | 动作、对白、镜头与原文映射 |
| 灯光特效 | 光线、色调、特效与提示词一致性 |
| 总监管 | 对照原文独立审稿，核对事实、因果、对白、时长 |
| 定妆审图 | 接收真实参考图和候选图，检查人物、道具、风格与清晰度 |
| 运镜 | 补全起止状态、动作节拍、视线、人群和转场，复核相邻分镜 |

角色可复用同一模型，也可选择不同来源。配置保存到项目快照；全局改动不会直接替换已开工项目。视觉角色必须使用适配的图片输入，不能把文字复核当成看图。

## 对白与镜头密度

原文引语形成对白账本，保留说话顺序、原文出处和删改理由。同一句台词多次出现需要分别落实，同镜问答也检查顺序。长对白应拆成主说、倾听、反应与承接镜，不能用无限拉长单镜替代。

新项目默认约 30 镜，提供更细的 36／40 镜等计划。节奏视图可按集、对白、缺图、待处理项和文字筛选；单镜展示计划时长、实际图像像素和拍摄单缺项。

## 先审当前分镜，再生成视频

定稿与分镜审核绑定当前图片、参考版本和拍摄单。替换人物、道具、分镜或关键拍摄要求会使旧审核失效。自动制作依次完成独立审稿、资产像素检查与邻镜审查；修复次数、并发与总请求量均受限。

请求次数上限不是价格预算。平台错误或余额失败保留任务并暂停；状态不明的付费提交不能自动重发。可继续查询原任务、重试媒体保存和本机合成。

## 声音与实际效果

按角色维护别名、发音、音色和情绪，绑定本机可播放的试听文件，导出台本。已删除或缺失的音频不可作为有效绑定；记录声音方案本身不自动合成、替换配音或进行口型修复。

逐镜播放后检查五项：画面是否稳定、动作是否成立、剧情是否推进、时长是否合适、设计是否合理。整片还需检查对白完整、口型、环境底声、切点、人物道具和人群连续性。自动生成不会写入人工接受标志。

## 续作与导出

续作可带入前作锁定图片、来源版本与已登记声音方案；设定变化时重新检查，不复制旧审核结论。制作资料导出包含对白账本、连续性快照、拍摄单和制作偏好，不包含 API Key，也不等于完整媒体备份。
