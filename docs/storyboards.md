# 定稿图与分镜

视频工作台右上角点击「定稿图与分镜」。此流程调用已接入的图像模型；不会自动提交视频任务。

1. 新建本机项目，粘贴整段创意或视频脚本，选择图像模型及画幅。当前视频描述会填入新项目。
2. 可补充人物、服装、配饰、场景和光线要求。点击「生成 1 张定稿图」，等待生成和本机保存完成。
3. 满意后点击「确认此图，作为共同参考」。不满意可重新生成，旧作品保留在作品库。
4. 默认有环境与出场、主要动作、细节展示、结尾定格四个镜头模板。它们是可编辑的镜头安排，不是语言模型自动拆解的脚本。按需要修改为具体动作与构图，最多添加 8 个镜头。
5. 点击「同时生成 N 张分镜」。每个任务都会传入同一张定稿图作为参考。分镜模型必须支持参考图，系统不会悄悄改为纯文生图。最多 3 个任务并发，其余排队；平台也可能有自己的队列。
6. 每个镜头有独立预览、状态、错误和重做按钮。可以下载，或加入当前视频草稿的参考图；视频模型支持时可设为首帧／尾帧。返回视频生成后检查提示词、素材、时长和尺寸，再自行提交视频。

新功能只提供图像准备流程，不会自动剪辑、配音或添加穿搭标签。相同参考图有助于保持一致，但生成结果仍需人工检查。对于不能直接接收比例参数的图像接口，比例写入提示词，像素尺寸保持模型默认值。

项目保存于本机 SQLite 的 storyboards 表，正常图像任务继续计入作品库和用量统计。编辑后点击「保存项目」；点击生成前也会先保存。生成状态在刷新后可恢复，未提交完成的图片任务不会因重启而自动重发。重复的同一次提交使用请求标识去重。

一次批量生成 N 个镜头会创建 N 条独立图像任务。重做全部会再次提交全部镜头；仅重做失败镜头更便于控制调用次数。定稿确认及素材转入视频草稿只处理本机已归档图片，不再次访问图片模型。输入素材维持现有每张 10 MiB 限制。

验证：tests/test_storyboards.py 使用隔离数据库和本机 HTTP 覆盖完整流程、同图引用、原子批量入队、重复提交去重、单镜头重做、队列容量、路径限制、重启及数据持久化。tests/test_storyboards_ui.js 覆盖视频草稿素材转入、能力限制和请求状态。真实厂商付费生成效果与浏览器视觉验收独立于这些测试。
