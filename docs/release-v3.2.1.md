# 光屿 AI 3.2.1

修复外部模型 API 被强制直连、无法使用电脑系统代理而超时的问题。

- 外部 HTTPS 模型目录、生成请求与任务查询默认使用 Python 标准代理发现：环境变量优先，否则读取 Windows 当前用户的手动代理。
- 保留已有按域名配置的本机代理路由；没有系统代理时直连。
- localhost、127.0.0.0/8 和 IPv6 回环始终直连，本地模型与工作台控制不经过代理。
- 系统代理例外规则继续生效；请求失败不会改线路重复提交生成，TLS 证书验证与禁止鉴权重定向保持不变。

升级后需要重启本机服务以加载修复；之后 Windows 手动代理变化会在后续请求生效。运行进程的环境变量需要重新启动后继承。PAC 自动配置脚本与 SOCKS 不是本次支持范围，请使用 HTTP／混合代理端口。

详细设置及验收规则见 [网络与系统代理](provider-network.md)。HTTP 401 只说明收到服务端响应，仍需核对 API Key、令牌分组和模型权限。
