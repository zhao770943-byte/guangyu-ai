# 第一集经验：斗气测试

这是光屿用户已经多次反馈后的制作案例。它描述本项目改编，不替代当前项目状态或小说原文。

## 事实与改编记录

- 萧炎：斗之气三段。报幕保留“萧炎，斗之气，三段！”
- 萧媚：七段。测试后应有收手、转身、略显得意/看不起萧炎的目光，然后自然离场。
- 萧薰儿：九段。薰读 xūn（一声）。九段后先有族人惊呼与讨论，再注意萧炎、接近、安慰；不能直接跳过去。
- 用户新增：萧承五段、萧岳六段、萧峻六段。均为萧姓族人；这三人是本片改编新增，不冒充原著人物或段位。
- 试听一旦确认，锁定已保存音频与版本；候选字母标签只对当轮试听有效，不凭角色名字重新抽取音色。

## 失败→修复→验收依据

| 问题 | 原因边界 | 后续做法 |
| --- | --- | --- |
| 主角从高处突然到石碑 | 缺走近与入场桥接，不只是视频模型差 | 远景建立位置→走向队列/人群→到测试位→贴掌 |
| 石碑每次都不同、没有手印 | 只写“石碑”，道具定稿与引用不充分 | 锁定形状、材质、正面五指掌印凹槽；每次看图 |
| 手从侧面贴、眼睛看错方向 | 手、石碑正面、视线三者未统一 | 同一侧轴线，掌面对石碑正面，视线落在接触/显示区 |
| 人群忽多忽少、像路人 | 没有同一场景队列与分组参考 | 以用户接受的较密集第二镜为基准，固定队列距离和密度 |
| 群演服装一致、站十五秒 | 只有人数没有调度，时长过长 | 不同年龄服装与身份组，分时视线/侧身/低声交流；有效几秒 |
| 所有反应只是两对聊天 | 没有剧情角色与不同反应 | 三段用不屑/冷漠/窃语的不同角度；九段用惊呼/对视/议论 |
| 萧媚退场慢、画面跳、无得意 | 缺表情落点与出场桥接 | 小幅扬眉/嘴角、收掌转身、正常步速穿过队列；衔接反应镜 |
| 人物倒退、随意点头 | 提示未约束动作终点，首帧动作冲突 | 明确脚步方向、机位、起止姿态，禁止无关点头/后退 |
| 报幕软或夸张 | 音色、表演、文字标点同时不稳 | 中年、粗粝厚重、例行公事；先小样试听，再锁定 |
| 姓名念两次、薰字错音 | 呼名与结果叠轨；TTS发音未检查 | 逐句台词表、独立合成文本；xūn，画面文本仍写薰 |
| 嘴部模糊或开合过大 | 反复嘴部后处理未改善源镜 | 优先换源镜、可信原生口型或切到反应镜，不继续糊嘴 |
| 第一段音效突变、片尾无背景声 | 素材声音与后期轨未统一 | 连续环境底声+局部特效；检查切点前后与最后几秒 |
| 余额足仍失败 | 令牌分组/型号权限/上游费用并非一项 | 看当前错误与原任务；读目录不代表可以生成；避免循环付费 |

## 版本边界

第一集曾有手工追加、修剪、混音的成片；最终时间线不一定与早期项目分镜表逐项相同。续作前应读取该版本渲染清单/时间线，不能把旧分镜表直接当最终剪辑。旧项目“完成”不等于自动勾选新审核表。

封面与视频同画幅；第一集最终横版为 16:9。下一集根据项目当前比例决定，不把抖音等同于必须竖屏。
